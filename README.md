# 成都手工女鞋工厂 - 阿里国际站选品上架项目

## 项目背景

本项目为成都手工女鞋工厂提供完整的阿里国际站产品上架解决方案，涵盖从产品选品、图片生成到文案创作的完整流程。

### 核心定位

- **产品类型**：手工女鞋（高跟鞋、靴子、乐福鞋、凉鞋、穆勒鞋等）
- **目标市场**：欧美中高端消费者
- **差异化定位**：不卷价格，卷工艺和定制能力
- **起订量**：MOQ 30双起
- **价格区间**：出厂价 $25-$80/双（零售 $80-$300）

### 竞争优势

1. **手工工艺**：成都传统制鞋工艺，Goodyear welt手工缝制
2. **真皮材质**：全粒面牛皮、羊皮、漆皮、麂皮等优质皮革
3. **定制服务**：Logo、颜色、材质、跟高均可定制
4. **设计师款**：异形跟、几何跟等设计感强的款式
5. **欧美审美**：符合西方市场审美的设计和品质

## 使用指南

### 产品上架流程

1. **选择产品**：从 catalog.md 中选择产品
2. **查看数据**：打开 product.json 查看完整规格
3. **生成图片**：使用图片URL或重新生成
4. **编辑详情**：修改 listing.html 中的产品名称和参数
5. **上传平台**：按阿里国际站要求上传

### 图片处理

生成的图片已存储在各个产品文件夹中：
- 使用 `file_to_url` 工具转换为可访问URL
- 或直接下载本地文件上传

### 文案优化

建议根据实际产品调整：
- 颜色选项
- 价格区间
- 定制选项
- 交期承诺
